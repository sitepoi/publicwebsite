# ADR-003 — C3 page resolution & RenderPlan

Status: Accepted

Date: 2026-08-15

## Context

Step C3 implements the pure page resolver (Section 9) and the RenderPlan pure
function. Several route-shape details and content semantics needed to be
fixed in implementation.

## Decision

1. **Route parsing (`parsePath`):** `''`/`'/'` → home; one segment → slug;
   two segments → `<cmsObjectType>/<id>`; exactly three segments starting
   with `t` → template (`/t/<template>/<contentId>`); any other `/t/...`
   shape → not-found; more than two non-`t` segments → not-found; `/app/...`
   parses as a capability route that resolves to not-found until M10
   registers capability routes. Segments are percent-decoded, trailing
   slashes trimmed.
2. **Page selection:** slug match (home = `home-page`, Q12) + language match
   (`meta.language`; records WITHOUT `meta.language` count as the site's
   default language — tolerant for pre-migration objects) + draft rule
   (`data.status` ≠ published hidden unless `preview`, Section 8/Q9).
   Object-detail pages (`/<cmsObjectType>/<id>`) apply the draft rule but no
   language filter.
3. **Templates:** `/t/<template>/<contentId>` resolves the template page
   object (slug = template, in the website folder) and exposes
   `templatedContentId` + `template` in the RenderPlan variables. Fetching
   the referenced content object (and Nunjucks rendering) is deferred to the
   template work in Section 24 / C4+ — the variable contract exists now.
4. **Siblings:** same `contentId`, other languages, sorted by language —
   feeds hreflang + the language switcher.
5. **RenderPlan:** pure `(siteConfig, pageObject, siblings, request)` —
   `html/css/js` come ONLY from `htmlPage.code.{html,css,js}` (data.html; no
   block rendering, Section 13). SEO = the fixed object SEO section (Section
   8). `structuredData` maps `seo.schemaItems` (parses `json` when it is a
   JSON string) with a default `WebPage` entry when empty — JSON-LD builders
   arrive in C4/M4. Chrome is carried via optional
   `siteConfig.chromeObjects.{header,footer}` (filled by C4 from the
   reserved-slug objects). hreflang URLs use `primaryHost` (fallback: the
   resolved host); hreflang + language switcher are sorted by language.
6. **`resolveLanguage`:** v1 has no locale path prefixes (Q4) — language is
   `settings.defaultLanguage`, fallback `'en'`.

## Consequences

- `lib/resolver/page.ts` has zero data-access imports (firebase-free);
  callers wire `PageObjectLoader` to the DataProvider (Section 6B).
- C4 can render any route kind immediately; template content lookup remains
  an open item tracked for the Section 24 template work.
